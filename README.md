# Манчкин на одного

Фанатская карточная игра по мотивам настольного «Манчкина»: вы против 1–3 ботов, которые дерутся, помогают за долю добычи и подкидывают гадости в ваши бои.

**Играть:** https://volik1987.github.io/manchkin/ — работает в браузере телефона, можно добавить на домашний экран (офлайн после первого запуска).

- Два сеттинга: **Классика** (эльфы, дварфы, подземелья) и **Русский манчкин** (богатыри, леший, Баба-Яга, Кощей, Змей Горыныч).
- Дополнения: скакуны, подручные, больше монстров и проклятий, двойные расы и классы.
- Все тексты карт оригинальные. Без сборки: чистые HTML/CSS/JS.

После правок поднимайте `VERSION` в `sw.js`, иначе у игроков останется старая версия из кэша.
